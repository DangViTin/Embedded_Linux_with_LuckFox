## Project Objectives

Create a complete MQTT system on Luckfox Pico Ultra W including:
- Local MQTT Broker (Mosquitto) **OR** Public Test Server
- Application reading AHT30 sensor data via I²C
- Publishing data to MQTT broker every 2 seconds
- Integration into Buildroot as an optional package
- Node-RED Dashboard for data visualization

## Quick Start Guide

**For users who want to get started quickly with the public test server:**

1. **Create package files** (Part 2) - use Option B configuration
2. **Add to Config.in** (Part 3.1)
3. **Enable in menuconfig** (Part 3.2) - select `aht30-mqtt`
4. **Build**: `make aht30-mqtt`
5. **Flash rootfs** to Luckfox
6. **Run on device**: `./usr/bin/aht30-mqtt`
7. **Subscribe from PC**: `mosquitto_sub -h test.mosquitto.org -t TamNguyen/aht30 -v`

**Estimated time**: 20-30 minutes (excluding build time)

**Common Code for Both Options:**
```c
// Read RAM info from /proc/meminfo
int read_meminfo(const char *key) {
    FILE *fp = fopen("/proc/meminfo", "r");
    if (!fp) return -1;
    char line[128];
    int value = -1;
    while (fgets(line, sizeof(line), fp)) {
        if (strncmp(line, key, strlen(key)) == 0) {
            sscanf(line + strlen(key), ": %d", &value);
            break;
        }
    }
    fclose(fp);
    return value; // kB
}

// Read CPU load (1 min) from /proc/loadavg
double read_cpu_load() {
    FILE *fp = fopen("/proc/loadavg", "r");
    if (!fp) return -1.0;
    double load = -1.0;
    fscanf(fp, "%lf", &load);
    fclose(fp);
    return load;
}

// Read ROM info using statvfs
void read_rom_info(unsigned long *total, unsigned long *free) {
    struct statvfs stat;
    if (statvfs("/", &stat) == 0) {
        *total = (stat.f_blocks * stat.f_frsize) / 1024; // kB
        *free = (stat.f_bfree * stat.f_frsize) / 1024;   // kB
    } else {
        *total = *free = 0;
    }
}

// Read integer value from sysfs
int read_sysfs_value(const char *path) {
    FILE *fp = fopen(path, "r");
    if (!fp) {
        fprintf(stderr, "❌ Error opening file: %s (%s)\n", path, strerror(errno));
        return -1;
    }

    int value;
    if (fscanf(fp, "%d", &value) != 1) {
        fprintf(stderr, "❌ Error reading value from: %s\n", path);
        fclose(fp);
        return -1;
    }
    fclose(fp);
    return value;
}

// Callback when MQTT connection is successful
void on_connect(struct mosquitto *mosq, void *obj, int result) {
    if (result == MOSQ_ERR_SUCCESS) {
        printf("✅ MQTT: Connected successfully to %s:%d\n", MQTT_BROKER, MQTT_PORT);
    } else {
        fprintf(stderr, "❌ MQTT: Connection failed: %s\n", mosquitto_strerror(result));
    }
}

int main() {
    struct mosquitto *mosq;
    int temp_raw, hum_raw;
    char payload[256];
    int retry_count = 0;
    const int max_retries = 5;

    int ram_total, ram_available, ram_used;
    unsigned long rom_total, rom_free, rom_used;
    double ram_total_mb, ram_used_mb, rom_total_mb, rom_used_mb;
    double cpu_load;

    printf("🚀 Starting AHT30-MQTT application...\n");
    printf("📁 Reading sensor from: %s, %s\n", SYSFS_TEMP, SYSFS_HUM);
    printf("📡 Sending MQTT to: %s:%d, topic: %s\n", MQTT_BROKER, MQTT_PORT, MQTT_TOPIC);

    // Initialize MQTT library
    mosquitto_lib_init();
    mosq = mosquitto_new("aht30-client", true, NULL);
    if (!mosq) {
        fprintf(stderr, "❌ Unable to create MQTT client\n");
        return 1;
    }

    // Register callback
    mosquitto_connect_callback_set(mosq, on_connect);

    // Connection retry loop
    while (retry_count < max_retries) {
        int rc = mosquitto_connect(mosq, MQTT_BROKER, MQTT_PORT, 60);
        if (rc == MOSQ_ERR_SUCCESS) {
            break;
        }
        fprintf(stderr, "⚠️  Retrying MQTT connection (%d/%d)...\n", retry_count + 1, max_retries);
        sleep(2);
        retry_count++;
    }

    if (retry_count >= max_retries) {
        fprintf(stderr, "❌ Unable to connect to MQTT after %d attempts. Exiting.\n", max_retries);
        mosquitto_destroy(mosq);
        return 1;
    }

    // Main loop
    while (1) {
        temp_raw = read_sysfs_value(SYSFS_TEMP);
        hum_raw = read_sysfs_value(SYSFS_HUM);

        // Read system information
        ram_total = read_meminfo("MemTotal");
        ram_available = read_meminfo("MemAvailable");
        ram_used = (ram_total >= 0 && ram_available >= 0) ? (ram_total - ram_available) : -1;
        read_rom_info(&rom_total, &rom_free);
        rom_used = (rom_total >= rom_free) ? (rom_total - rom_free) : 0;
        cpu_load = read_cpu_load();

        // Convert to MB
        ram_total_mb = ram_total / 1024.0;
        ram_used_mb = ram_used / 1024.0;
        rom_total_mb = rom_total / 1024.0;
        rom_used_mb = rom_used / 1024.0;

        if (temp_raw < 0 || hum_raw < 0) {
            printf("⚠️  Skipping cycle due to sensor read error\n");
        } else {
            double temperature = temp_raw / 10.0;
            double humidity = hum_raw / 10.0;

            // Check for valid values
            if (temperature < -40 || temperature > 85) {
                fprintf(stderr, "❌ Invalid temperature: %.2f°C\n", temperature);
            } else if (humidity < 0 || humidity > 100) {
                fprintf(stderr, "❌ Invalid humidity: %.2f%%\n", humidity);
            } else {
                // Create JSON with system information
                snprintf(payload, sizeof(payload),
                    "{\"temperature\":%.2f,\"humidity\":%.2f,"
                    "\"ram_total\":%.2f,\"ram_used\":%.2f,"
                    "\"rom_total\":%.2f,\"rom_used\":%.2f,"
                    "\"cpu_load_1min\":%.2f}",
                    temperature, humidity,
                    ram_total_mb, ram_used_mb,
                    rom_total_mb, rom_used_mb,
                    cpu_load);

                // Send MQTT
                int rc = mosquitto_publish(mosq, NULL, MQTT_TOPIC,
                                          strlen(payload), payload, 0, false);
                if (rc == MOSQ_ERR_SUCCESS) {
                    printf("📤 Sent successfully: %s\n", payload);
                } else {
                    fprintf(stderr, "❌ MQTT send failed: %s\n", mosquitto_strerror(rc));
                }
            }
        }

        sleep(SEND_INTERVAL);
    }

    // Cleanup (never actually reached)
    mosquitto_disconnect(mosq);
    mosquitto_destroy(mosq);
    mosquitto_lib_cleanup();
    return 0;
}
```

## Part 4: Testing and Verification (Two Options)

### Option A: Testing with Local Broker

#### 4.1A Configure and Start Local MQTT Broker on Luckfox

**After building and flashing the rootfs to Luckfox**, configure and start the mosquitto broker:

```bash

# Create configuration file
nano /etc/mosquitto/mosquitto.conf
```

Content of `mosquitto.conf` file:

```conf
# Basic configuration
listener 1883
allow_anonymous true

# Connection settings
max_connections 100
```

Start the broker:

```bash

# Terminal 1 - Start mosquitto locally
mosquitto -p 1883 -v -c /etc/mosquitto/mosquitto.conf -v
```

#### 4.2A Subscribe to Local Topic

```bash
# Terminal 2 - Subscribe to local topic
mosquitto_sub -h 127.0.0.1 -t sensors/aht30 -v
```

#### 4.3A Run Application (Local Version)

```bash
# Terminal 3 - Run application configured for local broker
./aht30-mqtt
```

Local MQTT subscriber will receive JSON data every 2 seconds:

```json
{
  "temperature": 25.6,

  "ram_used": 45.2,
  "rom_total": 5972.0,
```

### 5.3 Configure MQTT Broker Connection

#### 5.3.1 Add MQTT Broker Node

1. In Node-RED editor, drag **mqtt in** node from the left panel to the flow

3. Click the pencil icon next to "Add new mqtt-broker..."
4. Configure broker settings:

**For Local Broker (Option A):**
```
Server: 127.0.0.1 (or Luckfox IP address, e.g., 192.168.1.100)
Port: 1883
Client ID: (leave blank for auto-generate)
Username: (leave blank if anonymous)
Password: (leave blank if anonymous)
```

**For Public Test Server (Option B):**
```
Server: test.mosquitto.org
Port: 1883
Client ID: (leave blank for auto-generate)
Username: (leave blank)
Password: (leave blank)
```

5. Click **Add** or **Update**

#### 5.3.2 Configure MQTT Topic

In the mqtt in node:
- **For Local Broker**: Set Topic to `sensors/aht30`
- **For Public Server**: Set Topic to `TamNguyen/aht30`
- Set Output to: `a parsed JSON object`
- Set QoS to: `0`
- Click **Done**

#### 5.4.3 Build Flow Step-by-Step (Alternative Method)

**Step 1: MQTT Input**
- Drag `mqtt in` node
- Configure topic: `TamNguyen/aht30`
- Output: parsed JSON object

**Step 2: Add Function Nodes**

Create 5 function nodes with these codes:

**Temperature Function:**
```javascript
msg.payload = msg.payload.temperature;
```

**Humidity Function:**
```javascript
msg.payload = msg.payload.humidity;
return msg;
```

**CPU Load Function:**

```javascript
msg.payload = msg.payload.cpu_load_1min;
return msg;
```

**RAM Used Function:**
```javascript
msg.payload = msg.payload.ram_used;
return msg;
```

**ROM Used Function:**
```javascript
msg.payload = msg.payload.rom_used;
return msg;
```

**Step 3: Add Gauge Nodes**

Drag 5 `gauge` nodes (from dashboard section) and configure:

**Temperature Gauge:**
- Group: Sensor Data
- Label: °C
- Range: 0 to 50
- Units: °C

**Humidity Gauge:**
- Group: Sensor Data
- Label: %
- Range: 0 to 100
- Units: %

**CPU Load Gauge:**
- Group: System Dashboard
- Label: Load
- Range: 0 to 100
- Units: (blank)

**RAM Gauge:**
- Group: System Dashboard
- Label: MB
- Range: 0 to 170
- Units: MB

**ROM Gauge:**
- Group: System Dashboard
- Label: MB
- Range: 0 to 6000
- Units: MB

**Step 4: Connect Nodes**

Wire the nodes:
```
mqtt in → function (temperature) → gauge (temperature)
       → function (humidity) → gauge (humidity)
       → function (cpu) → gauge (cpu)
       → function (ram) → gauge (ram)
       → function (rom) → gauge (rom)
       → debug
```

## Troubleshooting

### Common Issues for Both Options

#### Sensor Reading Errors
```bash
# Check if AHT30 is detected
ls /sys/class/hwmon/hwmon1/
cat /sys/class/hwmon/hwmon1/temp1_input
cat /sys/class/hwmon/hwmon1/humidity1_input
```

### Option A Specific Issues

#### Local MQTT Connection Error
```bash
# Check if mosquitto is running
ps aux | grep mosquitto

# Check port
netstat -an | grep 1883

# Check firewall (if applicable)
iptables -L
```

#### Local Broker Won't Start
```bash
# Check config file syntax
mosquitto -c /etc/mosquitto/mosquitto.conf -t

# Check permissions
chmod 644 /etc/mosquitto/mosquitto.conf
mkdir -p /var/lib/mosquitto
chown mosquitto:mosquitto /var/lib/mosquitto
```

### Option B Specific Issues

#### Internet Connection
```bash
# Test internet connectivity
ping test.mosquitto.org

# Test DNS resolution
nslookup test.mosquitto.org

# Check if port 1883 is accessible
telnet test.mosquitto.org 1883
```

#### Public Server Connection Issues
```bash
# Try alternative public brokers if test.mosquitto.org is down
# Edit aht30-mqtt.c and change MQTT_BROKER to:
# "broker.hivemq.com"
# "mqtt.eclipse.org" (deprecated but sometimes available)
```

### Debug AHT30 Sensor
```bash
# Scan I2C devices
i2cdetect -y 2

# Check I2C permissions
sudo chmod 666 /dev/i2c-2
```
